## ✨ Features

- **🎹 Procedural Sound Generation:** Uses native Web Audio API oscillators, noise generators, and biquad filter nodes — zero external MP3s or network lag.
- **📈 Real-Time Oscilloscope:** Live canvas audio waveform visualizer processing time-domain frequency buffers.
- **🎛️ 16-Step Multitrack Matrix:** Kick 808, Snare Punch, Hi-Hat Crisp, Synth Lead (pentatonic scale), and Sub Bass.
- **🚀 Factory Beat Presets:** Cyberpunk 2077, Retro Synthwave, and Deep Tech House.
- **⚡ Dynamic Tempo:** 70–180 BPM tempo clock slider with real-time recalculation.

---

## 🛠️ Tech Stack

- **Audio Engine:** Web Audio API (AudioContext, AnalyserNode, BiquadFilterNode)
- **UI & Graphics:** HTML5 Canvas, Vanilla CSS3 Cyberpunk Neon Theme
- **Deployment:** Vercel
